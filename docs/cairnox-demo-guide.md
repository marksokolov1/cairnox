# CAIRNOX Demo Guide

## Start the demo

Prerequisites: Node.js 20.9 or newer and pnpm.

```bash
cd /Users/marksokolov/Desktop/cairnox
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

For a production-mode local demo:

```bash
pnpm build
pnpm start
```
